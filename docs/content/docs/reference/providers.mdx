## Adapter settings and limits

- **ACP.** Pass the invocation arguments required by the selected ACP agent. Resume needs negotiated session loading, and agent tools need HTTP MCP support. Root interruption on managed stdio stops the provider process. Native child tracking and interruption are covered for Claude Agent and Codex.
- **OpenCode.** Managed mode starts a server and can register run-scoped MCP. For external mode, configure a numeric loopback HTTP origin and, if needed, the name of the environment variable holding its password. External mode leaves MCP configuration and process lifetime with the host. Use one writer per native session. On 2.x, a disconnect between actual and observed inbox delivery can leave the prompt running on an external server.
- **Pi.** For agent tools, configure the absolute path to the separate [Huggler extension](https://github.com/MrLightful/huggler/tree/master/adapters/pi). It runs inside Pi’s runtime. Pi cancels interactive extension dialogs.
- **Muse.** Use the provider’s MSP server configuration. An unsupported interactive request fails the turn.
- **Usage.** The runtime aggregates reported input and output tokens for application runs, grouped by provider instance. Providers that omit usage contribute no report.

See [Configure providers](/guides/configure-providers/) for the registration and launch workflow.
