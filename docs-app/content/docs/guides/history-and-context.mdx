## Page and search one thread

Read a snapshot when you need the entire thread. For a history view, request a bounded page and keep its older-page cursor. Continue with the same thread and query until the cursor is exhausted. The query is a literal search with ASCII case folding.

Pages contain up to 100 messages, and previews may truncate text at 4 KiB. Fetch the full message by ID when a user expands a preview. If the runtime reports that history changed, discard the stale pages and restart the query. [Durability and recovery](/concepts/durability/#recover-a-view-from-its-cursor)

## Import an existing conversation

File imports copy visible history from Claude, Codex, or Pi into a new Huggler thread. An ACP Registry import refers to a native session that the configured instance can load. The runtime records provenance so you can find the original source later.

## Fork at a completed turn

Select the source thread and a completed run as the boundary of the fork.

| Mode | What the fork inherits |
| --- | --- |
| Native | A Codex native session fork on the original provider instance. Huggler verifies the inherited turn boundary. |
| Portable | A bounded, attributed message prefix. It can cross providers or instances. |
| Checkpoint | A portable prefix and a detached Git worktree at a captured commit. |

A completed fork can send its conversation result back to its direct parent. Git changes require a separate merge in the host’s workflow.
