---
title: Huggler
description: Embed durable coding-agent conversations in a Rust or TypeScript application.
---

Use the `huggler` crate to embed the runtime directly in a Rust application. In a TypeScript project, use `@huggler/sdk` to load the same runtime into Node.js. Both hosts can run a conversation in a Git checkout, handle provider requests, and recover the conversation from SQLite after a restart.
