title: Huggler
description: Embed durable coding-agent conversations in a Rust application.

Huggler runs in your application process. It stores conversation history, queued work, and command receipts in SQLite and communicates with agent providers through their native transports. Your application chooses how to present output, resolve approvals, and configure providers.
