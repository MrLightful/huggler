The SDK includes TypeScript declarations and loads a platform-specific Node-API addon. The preview supports Apple Silicon macOS and Linux x64 with glibc.

## Start here

- [TypeScript quickstart](/bindings/typescript/quickstart/) covers installing the preview tarballs, running a turn, and recovering the reply.
- [TypeScript API](/bindings/typescript/api/) lists options, promises, event types, and error codes.

## Build with TypeScript

- [Configure providers](/bindings/typescript/configure-providers/) with named installations and model discovery.
- [Control threads](/bindings/typescript/control-threads/) with an async event iterator, callbacks, and interruption.
- [Manage history and context](/bindings/typescript/history-and-context/) with snapshots, search, and pagination.
- [Observe collaboration](/bindings/typescript/collaboration/) from stored tasks and native-child events.

See the [feature matrix](/bindings/#feature-availability) for operations exposed by each binding.
