Use the Rust crate for the core runtime, agent orchestration, and optional application integrations. The crate requires Rust 1.94.1 or later and uses edition 2024.

## Start here

- [Rust quickstart](/bindings/rust/quickstart/) walks through running a Codex turn and recovering the reply after reopening.
- [Rust API](/bindings/rust/api/) lists runtime options, data types, and public entry points.

## Build with Rust

- [Configure providers](/bindings/rust/configure-providers/) with named installations and model discovery.
- [Control threads](/bindings/rust/control-threads/) with event streams, permission callbacks, queue controls, and attachments.
- [Manage history and context](/bindings/rust/history-and-context/) with pagination, imports, forks, and Git checkpoints.
- [Coordinate agents](/bindings/rust/collaboration/) using peer threads, owned delegation, or provider-native children.
- [Connect hosts and guests](/bindings/rust/connect-hosts/) using the authenticated HTTP endpoints.
- [Add application integrations](/bindings/rust/application-integrations/) for workspaces, schedules, repositories, or host services.
