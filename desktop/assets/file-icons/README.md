# File icons

The artwork is adapted from the built-in icon sprite in [@pierre/trees 1.0.0-beta.6](https://registry.npmjs.org/@pierre/trees/-/trees-1.0.0-beta.6.tgz). The symbols were converted to standalone SVGs with explicit fills. The JavaScript and TypeScript icons use solid square backgrounds. The Node.js icon uses a hexagon around the JavaScript glyph.
